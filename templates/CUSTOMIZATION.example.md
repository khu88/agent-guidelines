# 自定义配置模板

供使用者选择填写。删除不需要的字段，将已确定且适合公开的内容合入项目 AGENTS.md；个人或敏感配置保留在当前会话或已明确加载的本地文件中。

这是普通 Markdown 模板，不会自动读取、插值或授予权限。未填写的背景不推断，未填写的预算与权限不视为已批准。示例值和占位符不构成授权。

## 个人与交流偏好

| 字段 | 填写值或默认处理 |
| --- | --- |
| 身份或专业背景 | 未填写；可选，仅在影响解释深度时提供 |
| 研究或项目领域 | 未填写；按当前项目判断，不固定学科 |
| 回答语言 | 默认跟随用户当前请求 |
| 解释深度 | 默认按任务复杂度调整，覆盖影响结论的必要信息 |
| 输出格式 | 未指定时使用清晰段落、必要列表或表格 |
| 论文风格与投稿规范 | 未填写；如需采用，请给出目标要求或可核验来源 |

## 项目配置

| 字段 | 填写值或默认处理 |
| --- | --- |
| 项目目标与范围 | 待填写；不从模板推断任务目标 |
| 实际选用的模块 | 待选择并复制正文，不仅填写名称 |
| 构建、测试与验证命令 | 取自实际文件或已确认流程，不猜测可运行命令 |
| 资源约束与运行次数 | 未填写；涉及成本或实验条件时先确认 |
| 状态记录策略 | 不选 continuity 则不增加其记录要求；选用后按触发条件执行 |
| 状态记录路径 | 默认项目根目录 STATUS.md，或填写已有等效记录 |
| 交接记录路径 | 默认项目根目录 HANDOFF.md，或填写已有等效记录 |
| 实验记录与产物位置 | 沿用项目已有约定；否则在任务授权范围内确定 |
| 需要逐次批准的事项 | 待填写；未填写不取消 execution 中的批准边界 |
| 明确禁止的操作 | 待填写；已有禁止事项继续有效 |

## 有效预授权记录

每项预授权单独填写，并由用户明确确认启用。Agent 可以记录实际收到的授权，不能代用户授权、扩大范围或补写不存在的批准事实。

| 字段 | 填写值 |
| --- | --- |
| 目标与具体对象 | 未填写 |
| 允许的操作类型 | 未填写 |
| 范围与排除项 | 未填写 |
| 预算、币种与资源额度 | 未填写；不等于无限制 |
| 最大运行次数或其他数量上限 | 未填写 |
| 有效期限或失效条件 | 未填写 |
| 是否需要逐次批准 | 未填写；遵守用户已有检查点 |
| 明确批准的来源 | 未填写；仅记录实际批准的消息或文件依据 |

未完成确认前，上表只是待填写记录。不要用 AUTO_PROCEED、宽泛的“全部允许”或沉默替代具体授权；不要在这里保存密码、令牌或其他凭证。

## 合并前核对

- 私人背景只在任务确有需要时加入；公开版本保持可公开。
- 已有项目规则有冲突时，明确处理冲突，不靠覆盖顺序掩盖。
- 保留核心证据、真实状态与授权边界；只调整适用场景和实际参数。
- 若不使用某个模块，删除对它的配置期待，不假定其他文件会被自动读取。
